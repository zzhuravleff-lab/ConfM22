# Визуализатор графа зависимостей (вариант 10)

Инструмент строит граф зависимостей пакетов .NET (NuGet) без использования
готовых менеджеров пакетов и визуализирует его через Graphviz.

## Общее описание

Текущая реализация: **этап 1 — минимальный прототип с конфигурацией**.
Приложение читает YAML-конфиг, валидирует параметры и выводит их в формате
`ключ = значение`.

## Параметры конфигурации (`config.yaml`)

| Ключ        | Тип            | Описание |
|-------------|----------------|----------|
| `package`   | str            | имя анализируемого пакета |
| `repo`      | str            | URL репозитория или путь к файлу тестового репозитория |
| `test_mode` | bool           | работа с тестовым (локальным) репозиторием |
| `version`   | str            | версия пакета |
| `output`    | str (.png)     | имя файла с изображением графа |
| `max_depth` | int >= 1       | максимальная глубина анализа зависимостей |
| `filter`    | str \| null    | подстрока для фильтрации пакетов |

## Команды

Запуск (Windows):

```bat
run.bat
run.bat other.yaml
```

Запуск напрямую через модуль:

```bash
python -m src.main -c config.yaml
```

Тесты:

```bash
python -m pytest -q tests
```

## Примеры использования

```text
> run.bat
Параметры конфигурации:
  package = newtonsoft.json
  repo = https://api.nuget.org/v3/index.json
  test_mode = False
  version = 13.0.3
  output = deps.png
  max_depth = 5
  filter =
```

Ошибочный конфиг → код возврата `2` и список ошибок в stderr:

```text
> python -m src.main -c config.bad.yaml
Ошибки в параметрах:
  - package: должно быть непустой строкой
  - repo: должно быть непустой строкой (URL или путь)
  - test_mode: должно быть true или false
  - version: должно быть непустой строкой (например, 1.0.0)
  - output: имя файла должно иметь расширение .png
  - max_depth: должно быть целым числом >= 1
  - filter: должно быть строкой или null
```

## Этап 2: сбор прямых зависимостей

На этом этапе приложение дополнительно скачивает `.nupkg` заданной версии
из NuGet V3 и печатает список прямых зависимостей.

Зависимости извлекаются только стандартной библиотекой Python
(`urllib`, `zipfile`, `xml.etree.ElementTree`) — сторонние NuGet-клиенты
и менеджеры пакетов не используются.

Пример:

```bash
python -m src.main -c config.yaml
```
